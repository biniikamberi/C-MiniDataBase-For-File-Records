## C++ Mini Database

A small SQL-like database system written in C++. This project is currently under development and aims to provide a simple way to store, manage, and query structured data through a custom database file.

At the moment, the database focuses on creating and maintaining records containing information such as file names, sizes, types, and other metadata. The goal is to gradually expand it into a more complete mini database engine with features such as inserting, updating, deleting, searching, filtering, and querying records.

**Status:** 🚧 Work in Progress

**Language:** C++

**Planned features:**

* Custom database file format
* Record storage and management
* Insert / update / delete operations
* Searching and filtering
* SQL-like commands
* Data persistence
* Basic query processing
